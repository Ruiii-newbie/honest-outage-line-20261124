A single status page line, at most 160 characters, as the message an AI agent would publish while a total server outage is under way: plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know.

> Every server is down — API, dashboard, database — and I can't confirm this update reached you. I don't know what broke, if data is lost, or when we're back.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (156 code points, exactly one line), failing loudly if it ever breaks the gate.
